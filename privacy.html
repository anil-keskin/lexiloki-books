Privacy

Lexi & Loki books and the Safe Crossing game are made for young children, so we collect no personal information.

  • No accounts, no sign-up, no forms.
  • No cookies, no analytics, no ads, no third-party trackers.
  • The PDFs and the game contain no tracking code and work offline after download.

This website is hosted on GitHub Pages. Like any web host, GitHub may keep basic technical logs (such as IP addresses) for security; see the GitHub Privacy Statement. We do not receive or use these logs.

We follow COPPA (USA), GDPR (EU) and KVKK (Türkiye) by not collecting any data at all.
